# 🖥️ GitDesk

**GitDesk** هو حل برمجي خفيف وسريع لتحويل أي هاتف أو تابلت أندرويد إلى **شاشة ثانية متكاملة** وجهاز تحكم لقواعد بيانات ونظام **Linux** عبر الوصلة السلكية (USB) مباشرة وبأقل زمن تأخير ممكن (Ultra-low Latency).

## ✨ المميزات الرئيسية

* **⚡ ربط سلكي عالي السرعة:** بث واستجابة فائقة السرعة عبر وصلة الـ USB دون الحاجة لشريحة أو اتصال Wi-Fi محلي.
* **🎬 فك تشفير عتادي متوافق (Hardware Decoding):** دعم متقدم لترميز H.264/AVC ليضمن سلاسة العرض واستقرار الأداء حتى على الأجهزة الاقتصادية والمتوسطة.
* **🔄 بث مستقر (Zero Freeze):** معالجة كاملة لمشاكل تجمد الشاشة (0 FPS) وانقطاع الصورة أثناء العمل الممتد.
* **🎨 واجهة مستخدم حديثة:** شريط أدوات طافٍ (Floating Menu) يسهل الوصول السريع للأوامر مع شاشات تحميل انسيابية.

## 🚀 طريقة الاستخدام والتثبيت (Step-by-Step Guide)

### 1️⃣ إعداد جهاز الأندرويد (العميل)
1. قم بتحميل ملف **`GitDesk.apk`** وتثبيته على جهاز الأندرويد الخاص بك.
2. افتح إعدادات الهاتف (Settings) -> **حول الهاتف (About Phone)**.
3. اضغط على **رقم الإصدار (Build Number)** 7 مرات متتالية لتفعيل "خيارات المطور".
4. ادخل على **خيارات المطور (Developer Options)** وقم بتفعيل **تصحيح أخطاء USB (USB Debugging)**.

---

### 2️⃣ إعداد جهاز اللينكس (السيرفر)
1. قم بتحميل حزمة اللينكس **`GitDesk.deb`**.
2. افتح التيرمنال في المجلد الموجود فيه الملف وقم بتثبيته عبر الأمر:
   ```bash
   sudo dpkg -i GitDesk.deb
   ```
3. تأكد من تثبيت أدوات `adb` لتسهيل الاتصال السلكي:
   ```bash
   sudo apt update
   sudo apt install adb
   ```

---

### 3️⃣ تشغيل وقيم الاتصال السلكي
1. وصل جهاز الأندرويد بجهاز الكمبيوتر/العدّة عن طريق وصلة **USB** ممتازة.
2. سيظهر لك إشعار على شاشة الأندرويد يطلب **"السماح بتصحيح أخطاء USB"**؛ اختر **سماح (Allow)**.
3. افتح تطبيق **GitDesk** على جهاز الأندرويد.
4. قم بتشغيل تطبيق السيرفر من قائمة البرامج في اللينكس أو من التيرمنال:
   ```bash
   gitdesk
   ```
5. سيتعرف البرنامج تلقائياً على الجهاز الموصول ويدشن العرض السلكي فوراً!

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Linux Host:** Python / PipeWire / FFmpeg / ADB Bridge
* **Android Client:** Kotlin / Jetpack Compose / MediaCodec API (H.264)
